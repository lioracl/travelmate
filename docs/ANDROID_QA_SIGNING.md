## Required owner configuration

Use a securely held, existing QA keystore. Repository Actions secrets:
- TRAVELMATE_QA_KEYSTORE_BASE64: base64 encoding of the private keystore
- TRAVELMATE_QA_STORE_PASSWORD: keystore password
- TRAVELMATE_QA_KEY_ALIAS: signing key alias
- TRAVELMATE_QA_KEY_PASSWORD: key password
Repository Actions variable TRAVELMATE_QA_CERT_SHA256: public certificate SHA-256 (64 hex digits, optional colons).
Do not paste secrets into chat, logs, source or artifacts. The workflow decodes only to RUNNER_TEMP with restricted permissions and removes the keystore even on failure. Any partial configuration fails. With no configuration, CI explicitly labels its debug certificate ephemeral and exports signing-certificate.json with the artifact.

CI verifies the cryptographic signature with apksigner and then checks its public fingerprint against the configured identity. A mismatch fails before APK upload. Do not claim update compatibility merely from successful signing. Updates require the installed APK's certificate to match. The first stable QA build will require reinstall if its certificate differs from the currently installed 19692f2 APK. Data restoration acceptance does not replace signing continuity.
