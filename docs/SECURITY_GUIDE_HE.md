# מדריך אבטחה — TravelMate

## מה כבר מוגן

- הגישה למסד הנתונים ולקבצים מתבצעת רק לאחר התחברות ל־Supabase Auth.
- Row Level Security מגביל טיולים, מסמכים, חברי קבוצה והודעות למשתמשים המורשים בלבד.
- כספת המסמכים מצפינה קבצים בדפדפן באמצעות AES-GCM ומפתח שנגזר מסיסמת הכספת באמצעות PBKDF2.
- מפתח Gemini נשמר כ־Secret של Supabase Edge Functions ואינו נשלח לדפדפן.
- בקשות ל־AI דורשות משתמש מחובר, מוגבלות ל־60 בקשות ביום ומקבלות רק מידע מצומצם מהטיול.
- קבלות חדשות נשמרות בקובץ פרטי נפרד; תוכן הקבלה אינו נכלל עוד ב־JSON המסונכרן של הטיול.
- פונקציית ה־AI מקבלת בקשות רק מהאתר הרשמי ומסביבת הפיתוח המקומית.

## מרכז האבטחה באפליקציה

1. לחץ על **אבטחה** בתפריט.
2. בדוק שהחשבון מחובר ושכתובת הדוא״ל מסומנת כמאומתת.
3. לחץ על **הפעלת אימות דו־שלבי בחינם**.
4. סרוק את קוד ה־QR באמצעות Google Authenticator, Microsoft Authenticator או אפליקציה תואמת אחרת.
5. הזן את הקוד בן שש הספרות ולחץ על אישור.

באותו מסך ניתן:

- לצאת מהמכשיר הנוכחי בלי למחוק את המטמון המקומי.
- לצאת מכל המכשירים אם מכשיר אבד או נגנב.
- לצאת ולנקות את כל נתוני TravelMate המקומיים מהמכשיר. לפני פעולה זו יש לוודא שהסנכרון הושלם.

## אימות דוא״ל — הגדרה חינמית ב־Supabase

ב־Supabase פתח **Authentication → Sign In / Providers → Email** והשאר את `Confirm email` פעיל. לאחר מכן פתח **URL Configuration** והגדר:

- Site URL: `https://lioracl.github.io/travelmate/`
- Redirect URL: `https://lioracl.github.io/travelmate/**`
- לפיתוח מקומי: `http://127.0.0.1:8000/**`

שרת הדוא״ל המובנה של Supabase מיועד לניסויים ומוגבל. לפרויקט מסחרי מומלץ בהמשך להגדיר SMTP פרטי.

## CAPTCHA חינמי באמצעות Cloudflare Turnstile

1. צור אתר Turnstile בחשבון Cloudflare והוסף את `lioracl.github.io`.
2. ב־Supabase פתח **Authentication → Attack Protection → CAPTCHA**.
3. בחר Turnstile והזן את ה־Secret key — לעולם לא בקוד או ב־GitHub.
4. העתק את ה־Site key הציבורי לשדה `turnstileSiteKey` בקובץ `assets/supabase-config.js`.

כאשר השדה ריק, האפליקציה פועלת כרגיל בלי CAPTCHA. כאשר הוגדר, האתגר נוסף אוטומטית למסך ההתחברות ונשלח ל־Supabase בעת כניסה, הרשמה ואיפוס סיסמה.

## בדיקת אבטחה לאחר כל שינוי

הרץ ב־Supabase SQL Editor את `supabase/security_audit.sql`. כל שורת בדיקה צריכה להחזיר `PASS`. אין להריץ את הקובץ עם `service_role` מתוך דפדפן.

## גיבוי ללא תשלום נוסף

- שמור את קוד המקור ב־GitHub בלבד; מסמכים וקבלות נשארים ב־Storage הפרטי.
- אחת לחודש בצע ייצוא ידני של מסד הנתונים באמצעות Supabase CLI ושמור אותו בכונן מוצפן שאינו ציבורי.
- לפני שינוי מדיניות RLS או מחיקת נתונים, בצע ייצוא ידני נוסף.

## כללי שימוש חשובים

- אין לשתף סיסמת כספת, קוד אימות, קישור איפוס או מפתח API.
- אין לשמור צילום דרכון או פרטי כרטיס אשראי בצ׳אט או בזיכרונות רגילים; רק בכספת.
- בטלפון שאינו אישי, השתמש בסיום ב־**יציאה וניקוי המכשיר**.
- אם טלפון אבד, השתמש ממכשיר אחר ב־**יציאה מכל המכשירים** ושנה סיסמה.
